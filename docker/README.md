# Dev images (P11.1)

Three layered images for running the AI dev agents in a container instead of on
the host. Tags match `config/project-types.json`.

| image | from | adds |
|---|---|---|
| `ai-dev-base:0.1` | `node:22-bookworm-slim` | Claude Code + Codex (global npm), git, ripgrep, tini; unprivileged `node` user, `WORKDIR /workspace` |
| `ai-dev-cpp:0.1` | `ai-dev-base:0.1` | `build-essential cmake gdb ninja-build pkg-config` |
| `ai-dev-next:0.1` | `ai-dev-base:0.1` | `corepack enable` (pnpm/yarn on demand) |

## Build

```
docker/build.sh        # or docker\build.bat
```

Verified: `docker run --rm ai-dev-base:0.1 claude --version` etc.

## Reaching host services from a container

Containers talk to host services (Headroom, OmniRoute) via
`http://host.docker.internal:<port>` — see `config/ports.json`. Headroom must be
started with `HEADROOM_HOST=0.0.0.0` (default is loopback-only).
